### Key findings (measured, not assumed)

- **`pyarrow` is undeclared.** `datalake/parquet_storage.py` imports it at module
  level; it appears in NO pyproject.toml, no extra, and not in uv.lock. The inline
  comment "pyarrow is already installed (ParquetDataCatalog depends on it)" is
  false. Because `datalake/__init__.py` eagerly imports the loader chain,
  `import tradex_trading.datalake` fails outright — breaking backtest/replay boot.
  Cause of all 12 test failures + 15 collection errors in the trading suite.
- **`parity.yml` CI gate cannot run**: installs no extras (no pandas/pyarrow) and
  never installs pytest.
- **Documented test command is broken**: `python -m pytest domain/tests
  brokers/tests trading/tests` → 190 collection errors. All three test packages
  have `tests/__init__.py`, so pytest derives colliding module id `tests.*`.
  `--import-mode=importlib` does NOT fix it (root pyproject comment claims it
  does). Each package collects fine alone. Root `tests/` (4 arch-guard tests) is
  excluded from that command, so the boundary guards never run.
- **`full` extra is not a superset** — missing pandas.
