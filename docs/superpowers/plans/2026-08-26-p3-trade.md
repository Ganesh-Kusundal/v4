> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the openalgo-charts trade tier into the TradeX shell: a `TradingController` host fed by the backend's `/book` (already live), on-chart order lines + position markers + PnL, and a bracket-order UI that places Dhan/Upstox super-orders through a new backend endpoint. Part of the full UI-surface adoption (spec `docs/superpowers/specs/2026-08-26-full-ui-adoption-design.md`, Plan P3).

**Architecture:** The frontend already has `TradexTradeFeed` (place/modify/cancel over `/orders` + WS-triggered refetch) and the backend already serves `/api/charts/book` in the trade tier's vocabulary. P3 adds: (1) a small backend bracket endpoint `POST /api/charts/orders/bracket` that parses `stop_loss_price`/`target_price`/`trailing_jump` into a domain `OrderRequest` and calls `session.broker.submit_super_order` (capability-gated); (2) a frontend `trade.ts` that builds a `TradingController`-host — mapping `/book` orders/positions into the reference's `TradingOrder`/`TradingPosition`/`TradingTrade` shapes, attaching `TradeMarkersPrimitive`, and wiring the bracket UI + PnL readout. The reference's `TradeController`/`BracketGroup`/`WorkingOrderLine`/`PositionMarker`/`pnl.ts` are the drawing surface; the backend is the data + execution spine.

**Tech Stack:** Python (FastAPI `routes/chart.py` + `routes/orders.py`), domain `OrderRequest` (already has `stop_loss_price`/`target_price`/`trailing_jump`), TypeScript + Vite frontend, `openalgo-charts` trade tier.

## Global Constraints

- **Every order mutation through the existing execution spine** — the bracket endpoint delegates to `session.broker.submit_super_order`, NOT a new parallel path. Non-bracket orders continue via `/orders` unchanged.
- Capability-gated: bracket endpoint checks `capabilities.supports_super_order` (via `/extensions`-style check on the session broker); returns 501/422 when unsupported (paper broker). Never crash.
- Frontend: the trade tier's drawing is the reference's (TradingController/TradeMarkersPrimitive/order-line/position markers/bracket/pnl) — the host is wired to backend data; no order math invented.
- Existing gates stay green: analytics 324, golden 91, profiles 6, transforms 7, interface suite.
- Do NOT touch the unrelated working-tree files (`parallel_fetcher.py`, broker adapter work, untracked `data/`).
- Do NOT change the existing `/orders` routes' behavior or the domain `OrderRequest` (it already has the bracket fields).

```python
@router.post("/orders/bracket", dependencies=[Depends(verify_api_key)])
async def place_bracket_order(
    body: dict, session: Any | None = Depends(get_session)
) -> dict:
    """Place a bracket (super) order — entry + protective stop/target legs.

    Delegates to ``session.broker.submit_super_order`` (the Dhan/Upstox
    facade). Capability-gated: brokers without ``supports_super_order`` get
    422, and a missing session 502. Non-bracket orders keep using ``/orders``.
    """
    if session is None:
        raise HTTPException(status_code=502, detail="no session bound")
    broker = getattr(session, "broker", None)
    if broker is None:
        raise HTTPException(status_code=502, detail="broker unavailable")
    caps = getattr(broker, "capabilities", None)
    if caps is None or not getattr(caps, "supports_super_order", False):
        raise HTTPException(status_code=422, detail="broker does not support super orders")
    try:
        request = _build_bracket_request(body)
    except (KeyError, ValueError) as exc:
        raise HTTPException(status_code=422, detail=str(exc)) from exc
    try:
        order_id = broker.submit_super_order(request)
    except ValueError as exc:
        raise HTTPException(status_code=422, detail=str(exc)) from exc
    return {"order_id": str(order_id)}
```

```ts
export async function placeBracket(opts: {
  exchange: string; symbol: string; side: "BUY" | "SELL";
  quantity: number; price: number; stopLoss: number; target: number;
}): Promise<string> {
  const resp = await fetch("/orders/bracket", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      exchange: opts.exchange, symbol: opts.symbol, side: opts.side,
      order_type: "LIMIT", quantity: opts.quantity, price: opts.price,
      stop_loss_price: opts.stopLoss, target_price: opts.target,
    }),
  });
  if (!resp.ok) throw new Error(`bracket place failed (${resp.status}): ${await resp.text()}`);
  const body = (await resp.json()) as { order_id: string };
  return body.order_id;
}
```
